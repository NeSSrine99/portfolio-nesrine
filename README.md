#  Portfolio - Nesrine Nasri

This is my personal portfolio website showcasing my projects, skills, and experience as a Software Developer.

---

##  Overview

The portfolio is built with **Next.js**, **Tailwind CSS**, and **Framer Motion** for smooth animations and engaging user experience.  
It highlights my main projects, technical skills, and provides ways to get in touch with me.

---

##  Tech Stack

- Next.js (React framework)  
- Tailwind CSS for styling  
- Framer Motion for animations  
- JavaScript (ES6+)  
- Vercel for deployment  

---

##  Structure

- `/pages` - Contains website pages (Home, About, Projects, Contact)  
- `/components` - Reusable UI components with animations using Framer Motion  
- `/public` - Static assets like images and icons  
- `/styles` - Tailwind CSS configuration and custom styles
